# 🎬 Story Hive

A full-stack platform connecting writers and directors.

## Quick Start

### Backend
```bash
cd backend
npm install
node server.js
# Runs on http://localhost:5000
```

### Frontend
```bash
cd frontend
npm install
npm run dev
# Runs on http://localhost:3000
```

## Flow
1. Open http://localhost:3000
2. Click "Continue without login"
3. Enter your name and select Writer or Director
4. Writers post stories → Directors browse and click "Interested" → Deal created
5. Both parties confirm → Deal completed, full script unlocked
